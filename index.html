In-Class Exercise: Fork, Pull and Push (Sep 29, 2026)

This page is going to become a shared design project. The HTML stays the same for everyone, but each of you will write your own stylesheet for it.

To add your stylesheet, you'll use the same workflow designers and developers use to contribute to projects they don't own:

  1. Fork: make your own copy of this repository on GitHub: go to github.com/severinbunse/fork-pull-push and click Fork.
  2. Download: on your fork, click Code → Download ZIP, unzip it, and open the folder in VS Code.
  3. Style: in the themes folder, open the file with your first name, for example themes/kitty.css. It already lists everything on this page you can style, so you can focus on styling. To see your changes, open index.html in your browser, choose your name from the Stylesheet menu at the top of the page, and reload after every change. Change only your own file: no HTML, and no one else's CSS.
  4. Commit: on your fork on GitHub, open your CSS file and click the pencil icon to edit it. Select everything in the editor, paste in your code from VS Code, and click Commit changes.
  5. Pull request: on your fork, click Contribute → Open pull request, then Create pull request. I'll review it and merge it.
